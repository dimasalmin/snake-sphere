# iter6: читаемый HUD + управление + темп

Заявки Димы (17.08):
1. Счёт не помещался, миникарта перекрывала текст/панели.
2. Управление сложное, неудобно целиться в капли.
3. Длина «быстро расчёт» — не ощущается рост.

## Диагностика (live-код)
- #hud: flex по всей ширине + nowrap; миникарта fixed top-right 110px
  -> на узком экране чипы уезжают/наезжают на миникарту.
- Управление: half-screen hold. Чтобы ехать прямо - отпустить палец
  (инерция 0.46с довезёт поворот). Целиться в каплю при росте скорости
  невозможно; стрелок на еду за горизонт нет (только миникарта).
- Темп: рост скорости от счёта (score*0.015 рад/с за каплю) + течь
  ~0.088 рад/с при 2.8 рад (капля съедается за ~2.5с).

## Лучшие практики (моб. steering-аркады)
- Drag/steer: палец-джойстик, proportional horizontal offset -> поворот
  (не half-screen). Release -> straight.
- Off-screen goal arrows: стрелка у края экрана на цель вне view.
- HUD: не перекрывать play area; компактные чипы, pause в углу,
  minimap в углу с выделенным местом.
- Темп: фиксированная базовая скорость (рост только от буста),
  подтёк не должен съедать весь видимый рост.

## Изменения
- CSS: #hud слева, flex-wrap, правый край до миникарты; pauseBtn первым
  (top-left), чипы .chip (кратче подписи).
- JS: drag-руль: steerAnchor, steerTarget = clamp(dx / (0.25*innerWidth),
  -1,1); step: steerVel += (steerTarget - steerVel)*min(1,dt*12);
  P += TURN*steerVel*dt (TURN=1.9). Клавиши: steerTarget = R?1 : L?-1 : 0.
  Буст: второй палец ИЛИ правая кнопка мыши ИЛИ W/F/Shift.
  Направление буста = sign(steerVel) || (key.R?1:key.L?-1:1).
- Баланс: speed = BASE_SPEED * (boosting?2.4:1) (убран score-бонус);
  LEAK = min(0.014, LEAK_RATE*(bodyArc/START_ARC)^1.2) - при старте 0.014,
  при макс ~0.047 рад/с (капля = 4.7с).
- Стрелки: для каждой еды за горизонтом - точка на краю экрана,
  offset 26px, размер/альфа от углового расстояния; золотая - золотая.
- Стартовый текст: новое управление.
- Тесты: переписать под drag-руль (touchstart+touchmove dx), стрелки,
  темп (скорость не растёт со счётом), течь (капля = 4.7с).
